# GitHub 新手学生使用指南
写给没碰过 Git 的学生：从注册账号、装客户端，到提交、推送、多人协作，
按"一个完全不懂的人"的视角走一遍。附一份 23 页 PDF。

## 阅读
- [GitHub新手学生使用指南.pdf](./GitHub新手学生使用指南.pdf)　**推荐直接读这份**，23 页，带目录页码，排版已定格

## 说明

- 正文开头有一页「阅读路线」，先按自己的使用方式（只用网页 / 用桌面端 / 用命令行）跳到对应章节，不必从头读到尾。
- 文中出现的用户名、邮箱、仓库名都是占位符，换成你自己的即可；提交身份建议用网名或拼音缩写，不要写真实姓名，这个名字会永久写进每一次提交。
- 内容核对于 2026 年 10 月，桌面客户端与网页界面若有改版，以官方当期界面为准。
