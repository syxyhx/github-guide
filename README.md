# github-guide
面向学生的 GitHub 入门指南：从注册、安装客户端到提交、推送、多人协作，以"一个没碰过 Git 的人"视角来进行

## 阅读
- [GitHub新手学生使用指南.pdf](./GitHub新手学生使用指南.pdf)：推荐直接读这份，23 页，39 条目录带页码，排版已定格
- [GitHub新手学生使用指南.docx](./GitHub新手学生使用指南.docx)：可编辑的源文件，内容与 PDF 一致

## 说明
正文开头有一页「阅读路线」，先按自己的使用方式（只用网页 / 用桌面端 / 用命令行）跳到对应章节，不必从头读到尾。
文中的用户名、邮箱、仓库名都是占位符，替换成你自己的即可；提交身份建议用网名或拼音缩写，不要写真实姓名。
